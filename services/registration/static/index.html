A free-text note on one specific container — distinguishes it from same-type siblings. Not a printed label. E.g. "Mounted above reloading workbench", "Halloween crafts".

Attach photo

The reference photo, label visible as the touchpoint. Matters most for visually-variable types (a GB could be anything) — less for uniform ones (every HF looks the same). One per container; uploading again replaces it.

Find a container

Searches code, domain, locator, and whatever text vision-identify pulled off a reference photo (a product name, a printed spec, brand text — not verified fact, just search fodder). A manually-set locator always wins for display even when a match came from AI text.

Find by photo

Have the item in hand but don't know where it lives? Take a photo — this identifies it, text-searches for a match, and only if that's ambiguous (more than one candidate) falls back to comparing the photo itself against each candidate's stored reference photo. First call can be slow (the local model may need to load); it's not stuck.
